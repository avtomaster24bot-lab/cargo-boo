# Vezu

Мобильный веб-сервис грузоперевозок для Алматы: заказ почти в один тап, торг как в inDrive, статусы как в Яндекс Доставке и FaFa — всё в одном приложении.

Живое демо: [https://avtomaster24bot-lab.github.io/cargo-boo/](https://avtomaster24bot-lab.github.io/cargo-boo/)

Это публичная демо-версия. Любой, у кого есть ссылка, может открыть её в браузере и оформить заказ. Регистрация на сервере не нужна: вход — имя, роль (клиент или водитель) и обязательные согласия на обработку данных и на пользовательское соглашение. Данные хранятся в `localStorage` этого браузера.

## Что уже работает

- Мобильный PWA-интерфейс на русском, валюта — тенге, карта по умолчанию в Алматы.
- Выбор точек «откуда / куда» на карте OpenStreetMap (Leaflet): поиск адреса через Nominatim и тычок по карте с обратным геокодингом. Есть быстрые места (аэропорт, вокзалы, ТРЦ, рынки) и кнопка «Демо-маршрут».
- Типы кузова: каблук, газель, 3 т, 5 т, 10 т, фура, эвакуатор.
- Опции: грузчики, упаковка, страховка, срочно, «сейчас» или ко времени.
- Описание и фото груза (фото сжимается и сохраняется локально).
- Мгновенный расчёт цены по тарифу машины и расстоянию маршрута OSRM. Если публичный OSRM недоступен, используется запасной расчёт по прямой.
- Торг в стиле inDrive: клиент предлагает свою цену, водители присылают согласие или встречное предложение.
- Большая кнопка «Заказать за … ₸».
- Режим водителя: список ближайших заказов, принятие или встречная цена, статусы «принят → в пути к загрузке → загрузка → в пути к выгрузке → доставлено».
- Экран сопровождения заказа, чат (заглушка с быстрыми фразами), оценка после доставки, история.
- Способ оплаты заказа: наличные, Kaspi или карта через банк (Halyk / Freedom) — только выбор, реальных платежей нет. Номер карты в приложение не вводится и не хранится.
- Установка на телефон: кнопка «Установить Vezu» (баннер можно скрыть, постоянный пункт есть в профиле). На Android/Chrome открывается системный диалог установки, на iPhone показываются шаги Safari «Поделиться» → «На экран Домой». Если открыто не в Safari, просим перейти в него. В уже установленном приложении кнопка скрыта.
- Водителю после принятия заказа показывается напоминание не закрывать приложение, пока заказ выполняется; экран по возможности не гаснет (Wake Lock), при уходе со страницы есть предупреждение.
- Защита персональных данных: отдельные согласия при входе, [политика конфиденциальности](https://avtomaster24bot-lab.github.io/cargo-boo/privacy) и [пользовательское соглашение](https://avtomaster24bot-lab.github.io/cargo-boo/terms) (черновики для юриста), маскирование телефонов, выгрузка и удаление данных, обезличивание заказов старше 180 дней. Подробности — в `docs/PRIVACY_SECURITY.md`.
- Переключение ролей в профиле, чтобы на одном телефоне пройти и клиентский, и водительский сценарий.
- Абонемент водителя: при первом входе в режим водителя автоматически открывается бесплатный пробный период на 7 дней, на экране видно, сколько дней осталось. Тарифы: день 1 000 ₸, неделя 5 000 ₸, месяц 15 000 ₸ (лучшая цена). Цены задаются в `src/data/plans.ts`. Демо-оплата через Kaspi, Halyk или Freedom продлевает подписку, есть история оплат. Поля номера карты нет. Без активного триала или абонемента лента заказов размыта, принять или предложить цену нельзя. За 2 дня до окончания показывается напоминание.
- Схема будущей базы в `supabase/schema.sql`. К существующим проектам Supabase она **не применялась**.

## Как запустить локально

```bash
npm install
npm run dev
```

Сборка для GitHub Pages (базовый путь `/cargo-boo/`):

```bash
npm run build
npm run preview
```

## Как устроен проект

- React 19 + Vite + TypeScript + Tailwind CSS 4
- Карта: Leaflet и OpenStreetMap
- Маршруты: публичный OSRM
- Поиск адресов: Nominatim
- Состояние: модульный store и `localStorage` (`cargo-boo-v1`)
- Деплой: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)


## Монетизация (водители)

Клиенты заказывают бесплатно. Сервис зарабатывает на абонементе водителя, а не на комиссии с каждого заказа (модель можно позже совместить с комиссией).

| План | Срок | Цена | Примечание |
|------|------|------|------------|
| Пробный период | 7 дней | 0 ₸ | Один раз, автоматически при первом входе в режим водителя |
| День | 1 день | 1 000 ₸ | Смена или пиковый день |
| Неделя | 7 дней | 5 000 ₸ | ≈ 714 ₸/день |
| Месяц | 30 дней | 15 000 ₸ | 500 ₸/день, лучшая цена |

Цены и сроки меняются только в файле `src/data/plans.ts`. Покупка в демо не списывает деньги: выбранный план просто активируется или добавляется к текущему сроку. В рабочем сервисе оплата абонемента планируется через лицензированных операторов РК (Kaspi, Halyk, Freedom); приложение не принимает и не хранит реквизиты карт. За 2 дня до истечения водитель видит баннер-напоминание. Если подписки нет, заказы рядом скрыты за платным экраном.

В `supabase/schema.sql` добавлены таблицы `subscriptions` и `subscription_payments` для будущего бэкенда. К существующим проектам Supabase схема не применялась.

## Дорожная карта

- Настоящий вход по телефону и SMS, отдельные кабинеты клиента и водителя.
- Живой бэкенд (Supabase): заказы, офферы и чат в реальном времени, фото в Storage.
- Настоящая оплата абонемента через Kaspi, Halyk или Freedom, чеки, автопродление и (по желанию) комиссия с заказа.
- Отслеживание водителя по GPS, расчёт ETA в реальном времени.
- Межгород, догруз, регулярные перевозки и юрлица.
- Пуш-уведомления, модерация, антифрод и поддержка 24/7.
- Приложения для iOS и Android на той же логике.

## Важно

Демо не является полноценным перевозчиком: цена ориентировочная, водители в клиентском режиме имитируются. Профиль и заказы демо хранятся только в браузере. При этом адреса для карты и маршрута в демо могут уходить в публичные сервисы OpenStreetMap / Nominatim / OSRM, серверы которых находятся за пределами РК — это ограничение демо, его нужно закрыть до запуска (см. `docs/PRIVACY_SECURITY.md`). Политика и оферта — черновики и должны быть проверены юристом.
