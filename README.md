# Карго Боо

Мобильный веб-сервис грузоперевозок для Алматы: заказ почти в один тап, торг как в inDrive, статусы как в Яндекс Доставке и FaFa — всё в одном приложении.

Живое демо: [https://avtomaster24bot-lab.github.io/cargo-boo/](https://avtomaster24bot-lab.github.io/cargo-boo/)

Это публичная демо-версия. Любой, у кого есть ссылка, может открыть её в браузере и сразу оформить заказ. Регистрация на сервере не нужна: вход — имя и роль (клиент или водитель), данные хранятся в `localStorage` этого браузера.

## Что уже работает

- Мобильный PWA-интерфейс на русском, валюта — тенге, карта по умолчанию в Алматы.
- Выбор точек «откуда / куда» на карте OpenStreetMap (Leaflet): поиск адреса через Nominatim и тычок по карте с обратным геокодингом. Есть быстрые места (аэропорт, вокзалы, ТРЦ, рынки) и кнопка «Демо-маршрут».
- Типы кузова: каблук, газель, 3 т, 5 т, 10 т, фура, эвакуатор.
- Опции: грузчики, упаковка, страховка, срочно, «сейчас» или ко времени.
- Описание и фото груза (фото сжимается и сохраняется локально).
- Мгновенный расчёт цены по тарифу машины и расстоянию маршрута OSRM. Если публичный OSRM недоступен, используется запасной расчёт по прямой.
- Торг в стиле inDrive: клиент предлагает свою цену, водители присылают согласие или встречное предложение.
- Большая кнопка «Заказать за … ₸».
- Режим водителя: список ближайших заказов, принятие или встречная цена, статусы «принят → в пути к загрузке → загрузка → в пути к выгрузке → доставлено».
- Экран сопровождения заказа, чат (заглушка с быстрыми фразами), оценка после доставки, история.
- Способ оплаты: наличные, карта, Kaspi — только выбор, реальных платежей нет.
- Переключение ролей в профиле, чтобы на одном телефоне пройти и клиентский, и водительский сценарий.
- Абонемент водителя: при первом входе в режим водителя автоматически открывается бесплатный пробный период на 7 дней, на экране видно, сколько дней осталось. Тарифы: день 1 000 ₸, неделя 5 000 ₸, месяц 15 000 ₸ (лучшая цена). Цены задаются в `src/data/plans.ts`. Демо-оплата Kaspi или картой продлевает подписку, есть история оплат. Без активного триала или абонемента лента заказов размыта, принять или предложить цену нельзя. За 2 дня до окончания показывается напоминание.
- Схема будущей базы в `supabase/schema.sql`. К существующим проектам Supabase она **не применялась**.

## Как запустить локально

```bash
npm install
npm run dev
```

Сборка для GitHub Pages (базовый путь `/cargo-boo/`):

```bash
npm run build
npm run preview
```

## Как устроен проект

- React 19 + Vite + TypeScript + Tailwind CSS 4
- Карта: Leaflet и OpenStreetMap
- Маршруты: публичный OSRM
- Поиск адресов: Nominatim
- Состояние: модульный store и `localStorage` (`cargo-boo-v1`)
- Деплой: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)


## Монетизация (водители)

Клиенты заказывают бесплатно. Сервис зарабатывает на абонементе водителя, а не на комиссии с каждого заказа (модель можно позже совместить с комиссией).

| План | Срок | Цена | Примечание |
|------|------|------|------------|
| Пробный период | 7 дней | 0 ₸ | Один раз, автоматически при первом входе в режим водителя |
| День | 1 день | 1 000 ₸ | Смена или пиковый день |
| Неделя | 7 дней | 5 000 ₸ | ≈ 714 ₸/день |
| Месяц | 30 дней | 15 000 ₸ | 500 ₸/день, лучшая цена |

Цены и сроки меняются только в файле `src/data/plans.ts`. Покупка в демо не списывает деньги: выбранный план просто активируется или добавляется к текущему сроку. За 2 дня до истечения водитель видит баннер-напоминание. Если подписки нет, заказы рядом скрыты за платным экраном.

В `supabase/schema.sql` добавлены таблицы `subscriptions` и `subscription_payments` для будущего бэкенда. К существующим проектам Supabase схема не применялась.

## Дорожная карта

- Настоящий вход по телефону и SMS, отдельные кабинеты клиента и водителя.
- Живой бэкенд (Supabase): заказы, офферы и чат в реальном времени, фото в Storage.
- Настоящая оплата абонемента Kaspi / картой, чеки, автопродление и (по желанию) комиссия с заказа.
- Отслеживание водителя по GPS, расчёт ETA в реальном времени.
- Межгород, догруз, регулярные перевозки и юрлица.
- Пуш-уведомления, модерация, антифрод и поддержка 24/7.
- Приложения для iOS и Android на той же логике.

## Важно

Демо не является полноценным перевозчиком: цена ориентировочная, водители в клиентском режиме имитируются, персональные данные никуда не отправляются. Карты и маршруты зависят от публичных сервисов OpenStreetMap / Nominatim / OSRM и их правил использования.
